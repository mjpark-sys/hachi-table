# 하치네 집밥 (같이 먹는 온라인 밥상)

하치가 쿠첸 밥솥으로 갓 지은 밥을 차려 주고, **한 상(6명)에 둘러앉아** 밥을 먹으며 짧은 한마디를 나누는 멀티플레이 웹 게임.

## 실행
```bash
npm install
node server.js          # http://localhost:3000
```
- `PORT`: 포트 (기본 3000) · `TABLE_CAP`: 한 상 정원 (기본 6) · `TABLES`: 한 식당의 상 개수 (기본 6 → 식당 1곳 36명)
- 탭을 여러 개 열면 같은 상부터 채워집니다. 상이 차면 다음 상, 식당이 차면 새 식당이 열립니다.
- 테스트: `node test_server.js` (상 배정, 말 전달 범위, 쿨다운, 필터, 신고 차단, 퇴장)

## 한 끼 흐름
취사(8초, 칙칙·보글 소리) → 완료음 → 밥솥 누르기(뚜껑·증기) → 반찬 고르기(시간대별 3가지) → 밥그릇을 톡톡 눌러 10숟갈 → "잘 먹었습니다" 카드(저장·공유)
- 키보드: `Space/Enter` 뚜껑·한 숟갈, `1~3` 반찬
- 화면: 내 상은 크게, 식당의 다른 상은 위쪽에 작게 보입니다. 한 번 먹을 때 나오는 소리는 같은 상 사람 것만 들립니다.

## 말 걸기
하단 바에 버튼 5개: **프리셋 4개 + 직접 쓰기**
- 프리셋은 지금 단계에 어울리는 말이 맨 앞(강조)에 옵니다. 식사 전은 "맛있게 드세요", 식사 중반은 안부·날씨, 그릇이 비어 가면 "잘 먹었습니다".
  - 안부는 시간대별로 바뀌고(아침·저녁), 날씨 문구는 계절(월)에 따라 바뀝니다.
- 말을 받으면 위쪽에 **답례 2개**가 뜹니다(10초). 누르면 바로 답해집니다. 말풍선에는 안 읽은 표시(빨간 점)가 붙습니다.
- **직접 쓰기**: 한글 15자, 한 줄. 쿨다운 8초, 한 끼에 8회. 닉네임은 랜덤이라 익명입니다.
- 말풍선은 4초 뒤 사라지고, 한 화면에 최대 3개까지만 보입니다. 대화 기록은 남기지 않습니다.
- 친구 얼굴(아바타)을 누르면 **숨기기 / 신고**.

### 안전장치 (서버에서 처리)
- 비속어·혐오·성적 표현·자해/폭력 표현, 링크·이메일·전화번호 형태, 외부 연락 유도(카톡 등)를 막습니다. `filter.js` 의 `BAD_WORDS` 에서 관리합니다.
  - 띄어쓰기·특수문자·글자 반복(씨씨발)은 접어서 검사합니다. **글자 사이에 다른 글자를 끼워 넣는 우회(씨이발 등)는 아직 못 잡습니다.** 운영하면서 단어를 추가하세요.
- 서로 다른 사람 3명이 신고하면 그 사람은 직접 쓰기가 차단됩니다(프리셋은 가능). 신고된 문장은 `reports.log` 에 쌓입니다. **정기적으로 지우거나 보관 기간을 정하세요.**
- 프리셋은 서버가 가진 문구 id로만 전달되어 위조할 수 없습니다.

## 에셋 교체 (코드 수정 없음)
| 넣을 파일 | 효과 |

사운드 이름: `puff`(칙) · `bubble`(보글) · `steam`(긴 증기) · `chime`(완료음) · `lid`(뚜껑) · `spoon`(숟가락) · `chew`(씹기) · `ambient`(배경 루프)
→ **실제 쿠첸 밥솥 녹음(취사 칙칙, 증기, 완료 멜로디)을 넣는 것이 ASMR 품질을 가장 크게 올립니다.** (파일이 없을 때 콘솔에 404가 보이는 것은 정상입니다.)

## 문구 바꾸기
말 걸기 문구는 `server.js` 의 `PRESET`/`REPLY` 와 `public/game.js` 의 `PRE`/`REP` 에 같은 id로 있습니다. 두 곳을 같이 고치세요.

## macOS에서 `Documents` 폴더 안에서 실행할 때
VS Code 터미널이 `Documents` 접근 권한이 없으면 `EPERM` 오류가 납니다. 시스템 설정 → 개인정보 보호 및 보안 → **전체 디스크 접근 권한**에서 VS Code를 켠 뒤 완전히 종료했다가 다시 여세요.

## 배포
Node 서버 한 개로 정적 파일과 WebSocket을 함께 서비스합니다. Render, Railway, Fly.io 등 WebSocket을 지원하는 곳에서 시작 명령을 `node server.js` 로 두면 됩니다. https 주소에서는 자동으로 wss로 연결됩니다.
- 단일 프로세스라 재시작하면 식당이 초기화됩니다. 트래픽이 한 대를 넘으면 식당 목록을 Redis 등으로 옮겨야 합니다.

## 구조
```
server.js            식당·상·좌석 배정, 말 중계, 쿨다운, 신고
filter.js            직접 입력 문장 검사
public/index.html    UI (입장, 말 걸기 바, 답례, 신고 메뉴, 카드)
public/game.js       장면, 사운드, 진행, 네트워크, 말풍선, 카드
test_server.js       서버 통합 테스트
```


## v3 조작 (걸어 다니는 식당)
- 바닥 클릭 = 걷기 / 빈 의자 클릭 = 가서 앉기 / 하단 중앙 바: 🪑 자리에 앉기(일어나기) · 🍚 밥먹기 · 💬 대화하기
- 서 있는 채로 '밥먹기'를 누르면 가장 가까운 빈자리로 가서 앉은 뒤 밥을 짓습니다.
- 말은 가까이(330px) 있는 사람에게만 보입니다. 좌표·상 배치는 public/layout.js 한 곳(서버와 공용).
- 환경변수: PORT, HALL_CAP(식당 1개 정원, 기본 36)
- 알려진 한계: 장애물 충돌/길찾기 없음(직선 이동), 다른 사람의 걷기는 목표 지점 기준 보간, 하치·밥솥 연출은 내 화면에서만 움직임.

## v4 (3D)
- three.js 3인칭 화면: 솥곁살이 마을 언덕·돔집·솥 언덕집·강 + 몽글몽글 털 캐릭터. 그리기는 public/scene3d.js, 로직·소리·UI는 public/game.js.
- 드래그 = 시점 회전, 휠 = 확대/축소. three 는 public/vendor/ 에 들어 있어 인터넷 없이 동작합니다.
- 캐릭터 모양은 scene3d.js 의 makeFluffy() 한 곳, 배경 색·돔 배치는 같은 파일 위쪽.
- 알려진 한계: 하루 시간대(아침/저녁) 색 변화 없이 노을 한 가지, 충돌 없음, 서버 접속 100명 이상·저사양 기기 성능 미확인.
